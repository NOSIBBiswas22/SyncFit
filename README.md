## 📖 About the Project

**SyncFit** is a desktop application that connects university students with part-time jobs and internships that fit their class timetable. Instead of showing every listing, SyncFit compares a job's working hours with the student's free time and recommends only the opportunities that can actually work.

This project is developed as a course project at **Daffodil International University (DIU)**.

## ✨ Key Features

- 🗓️ **Timetable-aware matching** – jobs are matched against the student's class schedule
- ⚖️ **Workload guard** – warns about or blocks schedules that would overload the student
- 💡 **Match explanation** – shows *why* a job was recommended
-🧑‍🎓 **Student profile** – skills, preferences, and weekly availability
- 🏢 **Employer panel** – post and manage jobs and internships
- 🔍 **Search and filter** – browse opportunities by category, hours, and type

> Features are planned and may change as development continues.
